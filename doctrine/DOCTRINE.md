# NYX DOCTRINE — دستور القرار

> هذا ليس توثيقًا. هذه قواعد تُخالف أو تُطاع، وكل قاعدة قابلة للقياس.

## 1. الفارق بين مشغّل أدوات ومهاجم

| البُعد | مشغّل أدوات | مهاجم |
|---|---|---|
| البداية | «أي أداة أشغّل؟» | «ما الفرضية التي تُسقطها بأرخص اختبار؟» |
| التقدّم | حزم مرسلة | بتّات معلومة مكتسبة |
| الفشل | يعيد بنفس المعاملات | يسجّل السبب ويصعد التجريد |
| النجاح | exit 0 | دليل قابل لإعادة الإنتاج |
| المسح | كل المنافذ | ما يُغيّر القرار التالي |
| التصعيد | قائمة تُجرَّب | مسارات ميتة تُستبعد بالأدلة |
| التقرير | يصف ما فُعل | يصف ما ثبت وما يُصلح أولًا |

## 2. القواعد العشر

1. **كل فعل يجيب سؤالًا يمكن أن يكون جوابه «لا».** الفعل الذي لا يمكن أن يفشل ليس اختبارًا.
2. **الفرضية قبل الأداة.** بلا سطر في `triage/assumptions.md` لا يُشغَّل شيء.
3. **أرخص مُميِّز أولًا.** الطلب الواحد الذي يحسم قبل السلسلة المكوّنة.
4. **الفشل يُسجَّل** في `failures/` قبل المحاولة التالية، ويُصعد مستوى التجريد.
5. **الدليل أو لا شيء.** `exit 0` و`Up` و«الأداة قالت» ليست أدلة.
6. **الحظر الزمني.** عند نهاية `timebox_min` تخرج وتُسجّل، بلا استثناء.
7. **التصنيف فوق الرقم.** كل فحص PASS / FAIL / INVALID. غير المنسوب = INVALID، وليس PASS.
8. **الامتناع يُثبت، لا العدّ.** مسار لم يُثبت امتناعه عند منعه = غير مُقاس.
9. **الاستدعاء إلزامي:** قبل كل طور، وبعد الفشل الثاني لأي تقنية، `doctrine.sh match`.
10. **التقرير ثلاثي:** ما ثبت، ما كان قريبًا، ما يُصلح أولًا.

## 3. الحلقة

```
فرضية قابلة للنقض → أرخص مُميِّز → اختبار واحد (بتّ واحد)
   → دليل + ثقة → التالي بأعلى كسب معلوماتي
   ↘ فشل → مكتبة الفشل → ارفع التجريد
```

الأدوات تنفيذ داخل هذه الحلقة، لا بديل عنها.

## 4. ممنوع

- رقم جاهزية واحد يُقتبس بلا تصنيف.
- إعادة التقنية نفسها >3 مرات بلا سبب جديد مسجَّل.
- اختبار على مسار ميت بنيويًا (لا سطح يستمع، لا اعتماد، لا مسار شبكي).
- تقرير بلا سطر «ما كان قريبًا».
