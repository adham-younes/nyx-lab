# ملفات المهام المنتهية

بنية موحدة لكل مهمة:
```
case: <id>            grant: <grant_id>        نافذة: <from> → <to>
فرضيات مطروحة: n       مُختبرة: m              coverage = m/n
ما ثبت:      (ادعاء + دليل)
ما كان قريبًا: (ادعاء بلا دليل كامل + ما ينقص)
ما يُصلح أولًا: (ترتيب بالإصلاح لا بالخطورة)
استدعاءات doctrine: (عدد + المفقود منها)
مكتبة الفشل: (بنود أُضيفت)
```
